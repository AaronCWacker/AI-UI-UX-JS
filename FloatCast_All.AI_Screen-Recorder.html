    Recording guide, browser notes & diagnostics
    1 / Load and name

    Add your MP3s, select the first track, set timing, and choose a folder or filename before recording.

    2 / Share and float

    Choose the tab containing your game or presentation. Open the floating bar, then return to that tab.

    3 / Record and play

    Press Record. The countdown gives you time to get ready. Music starts after your intro and calls cut when it ends.

    Permissions: run this page over HTTPS or localhost. The browser asks you which surface to share; a webpage cannot bypass that prompt. Mobile browsers may not expose screen capture. The capability badges above reflect this device.

    Clean picture: a captured tab excludes other windows. Capturing an entire desktop can include this toolbar and other visible windows. Fading controls does not remove them from desktop footage. Browser and operating-system sharing indicators are not under this app's control.

    Audio: the MP3 is mixed into the recording through Web Audio. Shared/system audio is optional and browser-dependent. When shared audio is present, local music monitoring is disabled to prevent it being captured twice. Use headphones when recording a microphone.

    MP4: this app uses the browser's native MediaRecorder codecs. It probes support, requests MP4, and preserves the actual container. No renamed WebM, no background transcoding, no external libraries. A supported MIME type is not a guarantee that your hardware can encode at every resolution. H.264/AAC is preferred for MP4. Other native MP4 codecs are flagged because some editors and upload services do not accept them.

    Saving: choose a writable folder before starting for hands-free batch saves. Ordinary downloads follow browser preferences. Save as reserves one file; choose it again for another recording. Folder saves create unique filenames rather than replacing existing files. Keep this recorder tab open, and do not lock the device while recording.

    Controls: Alt+Shift+R = record, Alt+Shift+S = stop and save, Alt+Shift+H = collapse or expand. These shortcuts work only while this recorder or its floating controller has keyboard focus, not globally.

    Memory: native encoded chunks are held in memory until saved. A clip is stopped and saved at 512 MiB to avoid unbounded recording memory. Long playlists can be split with batch mode. Remove completed clips from the session list to free their in-memory copies.
