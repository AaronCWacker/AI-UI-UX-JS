🌊 Local world, explicit provenance

Drive works without a map service. Code, coordinates, road paths, lake outlines, car models, traffic and renderer are all inside this HTML. The file contains no runtime network code and its content security policy blocks connections.

Geography and rendering are separate. The embedded commute is still a hand-authored road/ramp draft. Constellation cache sharing can replace the flat fallback with cached measured elevations, ground imagery and mapped footprints. Missing areas stay explicitly unmeasured. It does not automatically correct the commute centerlines. This is not navigation.

The official work map link points to 1 Optum Circle; the supplied work address is 11000 Optum Circle. This build uses the linked campus coordinate, not a verified Building 2 entrance. The home shell uses your two-story specification; the campus shell uses your eight-floor specification. Architecture, vegetation, traffic and driveway orientation are placeholders.

Controls: Hold W to accelerate; double-tap W within 320 ms to hold current speed. S/Down/Space cancels cruise and brakes. Hold A/Left or D/Right to steer continuously. Short taps make small corrections. Hold the right mouse button over the 3D view and drag up for an overhead chase view or down for a low rear view; release to keep that angle. Left-drag still looks around. Right-drag never steers the vehicle. V still cycles camera presets. Release A/D to stop sideways movement and hold your current road position; there is no automatic lane change, lane-centering snap, or queued movement. Opposite input immediately changes direction. Steering is road-relative, with bounded yaw rather than a spin. Occupied lanes can still cause contact. The outer shoulder permits half a car width of overhang and has reduced grip. Divided-highway medians are not passing lanes. After six seconds without driving input the optional AI takes over at the road preset +10 mph, slowing for bends, vehicles and arrival. Steering, gas or brake returns control immediately. Contact removes front/rear/left/right armor; depleted armor exposes components to a severity-based failure roll. A breakdown automatically dispatches a tow truck and advances through a ten-second service sequence (1.5 s dispatch, 1 s hookup, 2.5 s tow, 5 s repair). No recovery key or instant repair. Speed, damage, traffic and towing are fictional game models.

Privacy: this HTML includes your real home and work coordinates. Publishing it publishes those coordinates. Nothing has been uploaded or published by this app.

Local north-up map image

Use a PNG/JPEG/WebP cropped exactly to known latitude/longitude bounds, with no margins. Select whether its rows are linear in latitude or Web Mercator. The app does not guess registration from a screenshot.

🏘️ Map footprints → detailed buildings

Facade system adapted from mrdoob’s Three.js procedural building generator: footprint faces → floor/bay layout → recessed glazing → cornices. Offline atlas shading replaces its WebGPU/TSL shader. Low-rise houses, shopfronts and modern offices remain separate styles; no random skyscraper grid replaces the map. Sky views help with footprint/roof placement, not unseen windows.

Local GeoJSON buildings / road context

Polygon / MultiPolygon features become fixed building footprints. LineString / MultiLineString features become extra context roads. Coordinates must be longitude, latitude. Mapped height, floor count, minimum height, roof shape/height and material tags are retained. Missing dimensions and all unobserved windows stay labeled as inferred. Route connections are never silently changed by importing nearby roads.

Traffic demand, buildings and lane geometry are simulation approximations. The 150 mph capability and protected +20 band are fictional arcade rules. This is not driving advice.

The first valid GLB becomes your car. Later imports become traffic variants. Select roles and orientation below; all files stay in browser storage. Head/tail lamp overlays follow the normalized vehicle bounds.

Basic offline loading supports uncompressed GLB 2.0 geometry and base colors. Install the optional Three.js renderer for embedded textures and node animations. Draco/KTX2 compressed assets require conversion before this build.
