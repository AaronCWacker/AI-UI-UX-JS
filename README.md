# 🧠 Hive-Mind Med Games — Top 10 Zeitgeist

Lens: human (AI + learning psych + perception) × AI swarm. Fun = desirable difficulty + shared mental model + a punchline.

| # | Hit | 3-sentence hive design |
|---|-----|------------------------|
| 1 | 🔌 **Operation** — Hasbro Christmas classic; surgeons-play videos in the millions | Tweezers stay, but the buzzer is a perception tutor: the swarm lights the safe gestalt path for one beat, then withdraws it. Misses become micro-lessons in tremor, not shame. A hive partner whispers one motor cue (“wrist, not fingers”) so adults replay for skill, kids for the buzz. |
| 2 | 🦠 **Pandemic** / Legacy — BGG staple, holiday coop gift | Four roles share one infection map; the swarm only speaks when the group’s model diverges (“you are treating the symptom city”). Legacy stickers unlock only after a debrief card the AI drafts from your actual mistakes. Fun is the argument that ends in a correct shared picture. |
| 3 | 🧤 **Surgeon Simulator** — viral on purpose; ~2.3M YouTube videos historically | Physics stays cursed, but a perception overlay ghosts the correct grip for 400 ms, then vanishes (dual coding, then retrieval). The hive logs which tool you always drop and spawns that tool in the next absurd op. Comedy is the teacher; competence is the joke’s punchline. |
| 4 | 🏥 **Two Point Hospital** — Theme Hospital heir; builder let’s-plays in the multi-millions | Illnesses stay silly; diagnosis is a real differential the swarm hides inside the cartoon. Staff training is spaced: a nurse forgets a step unless you reteach it three sessions later. Building the ward is fun because the AI names the bottleneck you refuse to see. |
| 5 | 🧫 **Plague Inc.** — Doctor Mike / strategy staple | You play the pathogen, then the swarm flips you to WHO mid-run with your own evolved traits as the enemy. Perception trick: the map desaturates where your mental model of spread is wrong. Winning both sides once is the only “cure” ending. |
| 6 | 🫀 **Bio Inc. Redemption** — House-style systems puzzle | Cause and cure are the same graph; the hive forces a commit before the lab returns, then shows the path you skipped. Redemption mode only opens if you can explain the miss in one sentence the AI scores for causal clarity. Fun is being wrong in public and fixing the model. |
| 7 | ✂️ **Trauma Center** / Team — rhythm surgery cult | The Healing Touch is a perception reset: slow time only after you name the anatomy. The swarm raises tempo on procedures you have already automated and slows novel ones (desirable difficulty). Team mode passes the tool only if your callout matches the other’s model. |
| 8 | 🧬 **Cytosis** + 💉 **Virus!** — BGG cell-bio euro + party card hit | Cytosis keeps worker placement; Virus! keeps the take-that organ steal. Hive glue: a 60-second “why this card” stamp both tables must answer or the steal fizzles. The AI deals a misconception card from last round so the party game quietly reteaches. |
| 9 | 📱 **Level Ex** / **Full Code** — clinician case games, demoed on med-ed YouTube | Real differentials, no cartoon. The swarm is a silent attending: it never gives the answer, it asks the one question that breaks your premature close. A perception strip shows which vital you did not look at. Fun is the status hit of a clean commit under a ticking board. |
| 10 | 🧩 **EndeavorRx** + **Friday Night at the ER** — FDA-cleared ADHD game + classic hospital table sim | EndeavorRx keeps adaptive attention thresholds; Friday Night keeps the 24-hour board. Hive bridge: table talk is transcribed into the next digital level’s distractors, so the team’s real failure becomes tomorrow’s stimulus. Fun is the group hearing its own bottleneck played back as a solvable level. |

## Outline — hive pair, one pass
- 👁️ Perception: show the gestalt once, then make them retrieve it
- 🧩 Learning psych: desirable difficulty, spaced reteach, one causal sentence
- 🧠 Superintelligence trick: swarm holds the group model, human holds the judgment
- 🎲 Fun rule: every miss mints the next toy, never a lecture

## 0 · First principles
1. **Never block the player.** Everything past the horizon loads, decodes and caches in the background.
2. **Everything is data.** Terrain is tiles, entities are GLBs, media is clips: keyed, pooled, cached.
3. **The user is in the world; the world is on the timeline.** Capture → scene → composition → share.
4. **One file, zero build.** Single HTML/JS, CDN libraries only, no npm, served from GitHub Pages.
5. **Cache once, travel instantly.** A visited place becomes a local place.

## 2 · World spine: streaming universe
**Scale ladder:** State → City → Block → Property → Room, each handing off to the next with no load screen.
- **Topography:** city maps drape roads, water and buildings over DEM heightmap tiles.
- **Rings:** *active* (render + physics) · *warm* (worker decode, GPU upload queued) · *cold* (IndexedDB / Cache API).
- **Prefetch:** rank tiles by time-to-arrival along heading × speed; horizon and off-screen first.
- **Budget:** fixed ms per frame for GPU uploads, idle time for the rest; LOD cross-fades, never pops.
- **States:** MN · WI · NY · FL · TX · CA · HI on a tiny US mini-map; ◐ loading, ● cached and jumpable.

## 3 · Entity pools: bulk GLB loader
Drop many `.glb` files; keywords in the filename, node names and glTF `extras` assign each to a pool.

| Pool | Keywords (seed list) | Behavior |
|------|----------------------|----------|
| 🚗 Ground | car, truck, bus, bike, tractor | road-following, drivable |
| ✈️ Air | plane, heli, drone, jet, bird, dragon | flight model, flyable |
| 🐾 Land creatures | dog, deer, horse, bear, moose | wander, herd |
| 🚤 Surface | boat, ship, kayak, duck, swan | buoyancy, drivable |
| 🐙 Underwater | fish, whale, shark, sub, octopus | swim volumes, schooling |
| 📦 Props | no match | static, instanced |

Pools are instanced, LOD'd and recycled; any pool member can become the player's vehicle.

## 4 · Presence: SOMA
- MediaPipe pose, hands and face drive a live 3D avatar while playing.
- Room capture becomes a textured backdrop mesh, portal-linked from the CavanTwin home.
- Body and room are recordable layers for the Media deck.

## 5 · Media deck: FrameForge
- **Player:** mp3/mp4 queue; music and lyric video in a resizable right sidebar.
- **Crop box:** drag a bounding box on the sidebar video; that region fills the main capture view.
- **Dual recorders:** canvas `captureStream(60)` + screen `getDisplayMedia`; AAC-first MP4 via `pickMime`, WebM fallback.
- **Mixer:** one `AudioContext` bus (music + game + mic) feeds the recorder while another mp4 keeps playing.
- **Timeline:** images, mp3, mp4 and captures snap to song length (loop, ping-pong, shuffle-cut, speed-ramp).
- **Output:** 9:16 · 1:1 · 16:9 exports into an IndexedDB gallery (play, download, delete).
